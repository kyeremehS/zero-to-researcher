## How I'm Working

For every concept, I aim to **connect the math to the code** I write — not treat them as separate tracks. Derivative rules get implemented as autograd operations. Gradient descent gets written by hand. Eigenvectors get computed and visualized. The goal is fluency in both notation and implementation.
